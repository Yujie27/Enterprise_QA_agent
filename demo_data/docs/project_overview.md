# 复杂规则约束下的智能决策系统研发说明

本项目面向复杂规则约束下的智能决策场景，目标是在有限信息条件下，根据当前状态、历史动作和候选动作集合，输出稳定、合理的决策结果。

## 主要难点

1. 状态空间复杂：局面信息包含当前手牌、已出牌、历史动作、可选动作等多类信息。
2. 动作空间较大：系统需要在多种候选动作中进行选择。
3. 合法动作约束强：模型输出必须经过规则校验，不能只依赖分类概率。
4. 离线指标和实际收益不完全一致：准确率提升不一定代表实战收益提升。
5. 工程落地要求高：模型需要接入服务接口，支持日志记录、时延统计和异常排查。

## 技术路线

系统采用状态特征构建、动作编码、模型训练、评测分析和服务部署的流程。训练阶段基于历史样本进行监督学习；评测阶段结合准确率、收益指标、流局率和时延等维度进行分析；部署阶段通过接口服务完成请求解析、模型调用和结果返回。
