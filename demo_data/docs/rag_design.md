# RAG 研发助手设计说明

研发文档与实验日志智能助手用于解决研发过程中查文档、查日志、复盘实验效率低的问题。

## 功能范围

1. 文档问答：对规则说明、项目文档、技术方案进行检索问答。
2. 日志检索：根据关键词或问题检索训练日志、对打日志中的相关片段。
3. 实验查询：读取实验记录表，返回指定模型版本或指标排序结果。
4. 总结生成：根据检索片段生成实验复盘或问题总结。

## 检索设计

第一版采用本地 TF-IDF 和关键词命中混合评分，适合处理中英文混合、版本号、指标名和日志片段。后续可以扩展向量数据库、embedding 模型和 rerank 模型。

## 工程设计

服务层使用 FastAPI，对外提供 ingest、ask、search_logs、experiments、agent 等接口。回答结果包含引用片段、来源文件和 chunk_id，便于追溯依据。
