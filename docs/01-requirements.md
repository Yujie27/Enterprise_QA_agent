# 01 用户、目标与范围

## 用户与目标

企业员工询问制度、报销规则等问题时，希望获得有原文依据、能指出适用范围的回答；遇到资料冲突或缺失时，希望 Agent 说明不确定性并提出必要追问。

## 成功标准

- Agent 能依据模型决策调用本地 `search_docs` 和 `read_doc` 工具。
- 回答引用资料 ID、版本、适用范围和原文；没有依据时不编造。
- 至少两条真实模型 Trace 展示模型观察不同工具结果后改变动作。
- 支持多轮上下文追问，并覆盖改写后的相似问题。
- 有工具调用上限；触顶后返回明确未完成状态。
- 离线模式能验证本地数据和工具流程，并明确声明它不证明模型决策能力。

## 本版范围

CLI；合成制度资料；轻量词项检索；单 Agent；OpenAI 兼容模型接口。暂不做网页界面、真实企业数据、文档解析、向量库和线上部署。
