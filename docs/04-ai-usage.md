# 04 AI 辅助使用与个人贡献

## AI 辅助范围

本仓库由 AI 辅助生成最小项目骨架、示例合成资料、工具接口草案和测试用例初稿。

## 个人需核验/补充

- 核对 AgentScope 实际安装版本与 API 调用。
- 配置本人可用的模型，运行至少两条真实模型轨迹，并检查每步工具动作和原文引用。
- 记录本人修改、运行命令、测试结果和发现的问题；不得把 AI 生成但未验证的结果描述为真实效果。
- 不提交密钥、真实制度或隐私数据。
