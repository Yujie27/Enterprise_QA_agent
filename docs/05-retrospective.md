# 05 复盘

## 初步判断

最难的部分不是检索本身，而是让 Agent 在证据充分、资料冲突和资料缺失三种状态下采取不同动作，并能用 Trace 证明这些动作来自真实模型调用。

## 实际改进与下一步

已完成 AgentScope 2.0.11 API 核对、真实模型多路径 Trace、工具失败注入、多轮上下文和相似问法改进。实际运行中发现模型在无结果时会持续改写直至上限，因此增加“连续两次无结果或同类错误后停止”的规则，同时保留触顶记录证明上限有效。

下一步若继续迭代，应优先增加引用自动校验和小型固定评测集，再考虑文档解析或语义检索。

v0.2.0 复查发现两个证据问题：原先的范围差异不等同于无法消解的制度冲突，且 `decision_basis` 是程序生成的摘要。为此补充同范围同日期的矛盾资料与移除冲突后的同题对照，并将模型公开理由、程序动作摘要分别记录来源。真实运行中还发现资料标题会影响模型搜索行为，移除“冲突资料”标签后完成最终对照。失败过程保留在评估文档中。
